Microsoft 可散布元件聲明
=========================

本產品隨附下列 Microsoft 可散布元件（Redistributable），其著作權屬 Microsoft Corporation：

- d3dcompiler_43.dll（DirectX 著色器編譯器，隨 mpv 引擎散布）

  （Microsoft Visual C++ 2015-2022 執行期，隨 AirPlay 輔助程式與 CUDA 版 AI 引擎散布）
